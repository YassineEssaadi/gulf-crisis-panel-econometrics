# 📄 Project Report

This directory contains the full academic report for the Gulf Crisis Panel Econometrics project.

## Expected file

```
econometrics_report.pdf
```

## How to add the PDF

1. Download the repository: `git clone https://github.com/YassineEssaadi/gulf-crisis-panel-econometrics.git`
2. Copy your PDF into this folder: `cp /path/to/report.pdf report/econometrics_report.pdf`
3. Commit and push: `git add report/ && git commit -m "docs: add project report PDF" && git push`

Alternatively, use the GitHub web interface: **Add file → Upload files**.
